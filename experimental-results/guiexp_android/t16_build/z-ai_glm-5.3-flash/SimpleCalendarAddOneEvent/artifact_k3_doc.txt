Open Simple Calendar Pro and wait for the calendar main screen.
Tap the floating 'New Event' button; if the event editor does not open, tap it again.
In the event editor, type {event_title} into the text field hinted 'Title'.
Type {event_description} into the text field hinted 'Description', directly below the title field.
Tap the start-date row, the clickable row showing a date string (it follows the two text fields), to open the date picker.
In the date picker, make sure {month} {year} is the displayed month; swipe the calendar if it is not.
Tap the calendar cell for day {day} of that month, then tap 'OK' to confirm the dialog.
Leave the end-date row untouched; the event ends on the same day.
Tap the start-time row, the first row showing a HH:MM time, to open the time picker.
In the picker's hours list, tap the entry described '{hour} hours' (scroll the list if it is not visible); the minutes stay at 00.
Tap 'OK' to confirm the start time.
Tap the end-time row, the second HH:MM row, to open the time picker again.
There is no duration field: the end time must be the start time plus {duration_mins} minutes.
In the picker, tap the minutes selector (the view labelled like '0 minutes') to switch from the hours list to the minutes list.
If {duration_mins} is 60 or more, first set the end hour to {hour} plus the whole hours, confirming as needed.
Tap the entry '{duration_mins} minutes' in the minutes list (scroll if needed).
Tap 'OK' to confirm the end time; every picker change is discarded unless confirmed with 'OK'.
Check the form: title, description, start date, start time {hour}:00, and end time start-plus-{duration_mins} minutes all look right.
Tap the 'Save' button to store the event; the app returns to the main calendar screen.
If the editor is still open after tapping Save, tap Save again.
