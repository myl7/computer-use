Markor — delete note {file_name}

1. Launch Markor and wait for its main file-list screen (recognizable by the "Markor" title and the create-new-file button).
2. In the file list, locate the row whose title is exactly {file_name}, extension included; match by title, never by row position, because several other notes are listed.
3. If that row is not visible, scroll the list down and look again; if it still cannot be found, stop with an error.
4. Long-press the {file_name} row exactly once to put it into selection mode; do not tap it, or the note opens instead.
5. Verify the target row is shown as selected before going on.
6. In the selection top bar that appears, tap the "Delete" icon; this button deletes only the currently selected note, so the correct row must be selected first.
7. A "Confirm Delete" dialog opens; its text names the note, sometimes without the extension — check it refers to {file_name} and not to another note.
8. Tap the "OK" button inside the dialog to finalize the deletion; dismissing the dialog or pressing back cancels it.
9. Confirm {file_name} no longer appears in the file list, and that every other note remains untouched.
