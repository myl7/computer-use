Delete the note in Markor named {file_name}; leave every other note untouched.

1. Open the Markor app and wait for its main screen: the title "Markor" with the note file list.
2. If the main screen did not appear, go to the home screen, relaunch Markor, and wait again.
3. On the file list, locate the row whose title matches {file_name} exactly, extension included; its accessibility description reads "File {file_name}".
4. Never pick a row by its position — the list holds several other notes that must survive.
5. If the target row is not visible, scroll the list down and search again; repeat until found.
6. Long-press the {file_name} row. This selects it and turns the top bar into a selection bar.
7. Confirm selection mode is active: the top bar now offers action icons such as Delete instead of the normal toolbar.
8. Tap the Delete icon (content description "Delete") in the selection top bar. It deletes only the currently selected row, so the long-press must have selected {file_name}.
9. Wait for the "Confirm Delete" dialog to appear.
10. Check that the dialog names {file_name}; if it names a different note, dismiss it, reselect the correct row, and retry.
11. Tap "OK" in the dialog to confirm the deletion.
12. Verify the note list no longer contains {file_name} and all other notes are still present. Done.
