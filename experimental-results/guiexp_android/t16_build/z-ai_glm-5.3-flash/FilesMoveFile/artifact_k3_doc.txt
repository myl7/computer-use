Open the Files app and wait for its main screen.
Tap the "Show roots" hamburger button to open the navigation drawer.
In the drawer, tap the sdk_gphone_x86_64 storage root entry; match it by its name or name prefix, as the exact label can vary slightly per emulator.
In the storage root listing, tap the row titled {source_folder}; scroll down first if it is not visible.
Inside {source_folder}, locate the row titled exactly {file_name}; the folder holds other files, so match the full name with extension.
Scroll down only if {file_name} is not visible; once visible, do not scroll further.
Long-press the {file_name} row to enter selection mode.
Tap the "More options" overflow button in the selection bar; if it is absent, no row is selected, so repeat the long-press.
Tap "Move to…" in the overflow menu; use Move, not Copy, because the source file must be removed for the task to succeed.
A destination picker opens; nothing on screen indicates the file is waiting to be pasted, so continue without expecting a clipboard marker.
In the picker, tap "Show roots" again to open its navigation drawer.
In the picker's drawer, tap the sdk_gphone_x86_64 storage root entry; match its exact label to avoid the "Files on …" title row.
Scroll the picker's folder list down until {destination_folder} is visible.
Tap the row titled {destination_folder}.
Tap the "MOVE" confirmation button (not "CANCEL"); it only finalizes after the destination folder has been entered.
Verify afterwards that {file_name} exists in {destination_folder} and no longer appears in {source_folder}.
