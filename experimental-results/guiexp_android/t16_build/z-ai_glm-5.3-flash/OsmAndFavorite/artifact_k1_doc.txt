OsmAnd — Add a favorite for {location}

1. Launch the OsmAnd app; wait for the map screen with its floating controls.
2. Tap the "Search" button on the map screen.
3. On the search screen, tap the search field (hint "Type to search all").
4. Type {location} VERBATIM into that field — never reformat, split, or round it; a place name or a "lat, lon" pair both go into this one field.
5. Press Enter/submit to run the search.
6. If the search reports no results ("Could not find anything"), tap the "INCREASE SEARCH RADIUS" row and wait for results; repeat if needed.
7. From the results list, tap the row whose title matches {location} (match by the row's title text, not by distance labels, which vary with GPS position).
8. On the place panel that opens, tap the FAVORITES control (the star icon) — NOT the adjacent marker control; only favorites.gpx is read by the oracle.
9. In the dialog that follows, accept the app-proposed name as-is (confirm/save without editing).
10. If a map context menu remains, press Back to dismiss it and return to the map.
11. Verify the favorite was saved (star/favorite visible for {location}); if any step's control is missing, re-check you are on the expected screen before retrying.
