Open the OsmAnd app and wait for its map screen (map controls such as Search are visible).
Map screen: tap the Search (magnifier) button to open the Search screen.
Search screen: tap the search input field showing the hint "Type to search all".
If that field is pre-filled with an earlier query, tap the Clear (X) button next to it before typing.
Type {location} into this one field exactly as given — never reformat, round, or split it; place names and "lat, lon" pairs both go here verbatim.
Wait for the results list to refresh; do not submit with the keyboard or tap elsewhere.
Results list: tap the first (topmost) row matching {location}.
Coordinate results may be shown reformatted (degree/compass style, e.g. "…° N, …° E"); match the row by its numbers, not by exact text.
Do not tap the search field itself when matching — pick a result row below it.
If the screen instead shows "Could not find anything" with an "INCREASE SEARCH RADIUS" label, tap that label once to widen the search, then recheck the list.
Never tap "INCREASE SEARCH RADIUS" repeatedly — recorded runs show looping there never reaches the goal.
If there are still no results, tap Clear, retype {location} verbatim, and check the list again.
Tapping the matching row opens the place panel (bottom context menu) for that point.
Place panel: tap the control labeled "Marker".
Do not tap the favorites star beside it — the star saves a favorite, not a map marker, and only the marker store counts for this task.
The marker is stored the instant you tap "Marker"; no confirmation dialog appears and none is needed.
Finish by confirming a marker flag for {location} is now shown on the map.
