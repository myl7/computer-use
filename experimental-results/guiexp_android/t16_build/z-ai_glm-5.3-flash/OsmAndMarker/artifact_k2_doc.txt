OsmAnd — Add a location marker for {location}

1. Open the OsmAnd app and wait for the main map screen (it shows a Configure map control) to load.
2. On the map screen, tap the Search button to open the search overlay.
3. On the search screen, tap the search field showing the hint "Type to search all".
4. Type {location} into the field VERBATIM: never reformat, round, or split a "lat, lon" pair — the same field accepts place names and coordinates.
5. Wait for the results list to appear below the field.
6. TRAP: if the screen shows "Could not find anything" with an INCREASE SEARCH RADIUS label, do not tap it repeatedly; tap the Clear (X) button in the search field, retype {location} exactly as given, and search again.
7. TRAP: tap a result ROW, never the search field itself; the row's text must correspond to {location}.
8. TRAP: for coordinate input the result row displays the values reformatted (degrees with N/S/E/W), so match the row by its numbers, not by the literal typed string.
9. Tap the FIRST matching result row; this opens the place panel (context menu) over the map.
10. On the place panel, tap the control labeled "Marker".
11. TRAP: use the Marker control, NOT the favorites star next to it — the star saves a favorite, while only the Marker control writes to the marker store this task checks.
12. The marker is stored immediately on the tap; no confirmation dialog appears, so do not wait for one or tap further.
13. If no "Marker" control is visible, the place panel did not open — go back and tap the result row again.
14. Done: the marker for {location} is set on the map.
