Open the Files app.
On the Files home screen, tap the hamburger button to open the navigation drawer.
In the navigation drawer, tap the storage root named sdk_gphone_x86_64.
On the storage root screen, tap the folder row named exactly {source_folder}.
In the source folder, long-press the row named exactly {file_name}.
On the selection bar, tap the overflow (three-dot) menu.
Tap "Cut" from the overflow menu.
Use the back button to return to the storage root screen.
On the storage root screen, tap the folder row named exactly {destination_folder}.
In the destination folder, tap "Paste".
If a confirmation dialog appears, confirm it.
The storage root is not the Files first screen; open the drawer first.
Match the file row by its exact name; other files are present.
After cutting, nothing on screen marks the clipboard; proceed straight to paste.
Use Cut, not Copy, because the oracle verifies the source file is gone.
