Open Files on Android.
If Files does not start at the sdk_gphone_x86_64 storage area, tap the hamburger/menu button.
In the drawer, select the sdk_gphone_x86_64 storage area.
On that storage root, tap the top-level folder {source_folder}.
Scroll if needed and find the row whose title is exactly {file_name}; ignore other files.
Long-press that {file_name} row.
On the selection bar, open the overflow menu and tap Cut.
Remember: no on-screen clipboard marker appears after Cut; continue normally.
Return to the sdk_gphone_x86_64 storage root using the drawer or Back.
Tap the top-level folder {destination_folder}.
In {destination_folder}, open the overflow menu and tap Paste.
If a picker or dialog appears, choose {destination_folder} and confirm Paste/Move.
Wait for the file operation to settle and the list to refresh.
Verify {file_name} now appears in {destination_folder}.
Verify {file_name} is gone from {source_folder}; if it remains, you used Copy instead of Cut and must redo.
Do not use Copy at any point; the move requires Cut and Paste.
