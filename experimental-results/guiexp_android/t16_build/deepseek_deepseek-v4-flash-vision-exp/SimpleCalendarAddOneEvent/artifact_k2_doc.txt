Open Simple Calendar Pro.
On the main calendar, tap the day cell for {day}.
Tap the new-event plus button.
If a menu appears, choose the row titled "New event".
On the new-event screen, tap the Title field and type {event_title}.
Tap the Description field and type {event_description}.
Tap the Start date row.
In the date picker, navigate to {year}-{month} if needed, then tap the day number {day}.
Confirm the date picker with OK.
Tap the Start time row.
In the time picker, set the hour to {hour} and the minute to 0.
Confirm the time picker with OK.
Calculate the end time: start at {hour}:00 and add {duration_mins} minutes.
Tap the End time row.
In the time picker, set the end hour and end minute to the calculated values.
Confirm the time picker with OK.
Tap the Save/check button.
