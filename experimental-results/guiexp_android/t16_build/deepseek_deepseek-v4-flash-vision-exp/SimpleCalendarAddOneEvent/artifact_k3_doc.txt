Open Simple Calendar Pro from the launcher.
On the main calendar screen, tap the "New Event" button to open the event editor.
In the event editor, tap the Title field and type {event_title}.
Tap the Description field and type {event_description}.
Tap the Start date row. In the date picker, select the day {day} in {month} {year}, navigating months if needed. Confirm with OK.
Tap the Start time row. In the 24-hour time picker, select the hour {hour} and the minute 00. Confirm with OK.
There is no duration field. The end time is the start time plus {duration_mins} minutes; carry an hour if the minutes reach 60.
Tap the End time row. In the time picker, select the computed end hour and end minute. Confirm with OK.
In every picker, select rows by their visible labels (e.g., the day number, "18 hours", "00 minutes") and always press OK. The pre-filled start date/time are replaced by your selections.
Tap the Save button to create the event.
