Open Simple Calendar Pro.
On the main calendar screen, tap the plus/FAB to start a new event.
In the new-event screen, tap the Title field (first text field), clear any pre-filled default text, and type {event_title}.
Tap the Description field (second text field) and type {event_description}.
Tap the Start date row.
In the date picker dialog, set the date to {year}-{month}-{day}, then confirm with OK.
Tap the Start time row.
In the time picker dialog, set hour {hour} and minute 00, then confirm with OK.
Do not look for a duration field; duration is set through the end time.
Compute the end time by adding {duration_mins} minutes to {hour}:00.
Tap the End time row.
In the time picker dialog, set the computed end hour and minute, then confirm with OK.
If the computed end time crosses midnight, open the End date row and set it to the next day, then confirm with OK.
All date and time picker dialogs must each be confirmed with OK before leaving them.
Tap Save/checkmark to save the event.
The app returns to the main calendar with the event created.
