Launch OsmAnd and wait for the map screen to load.

On the map screen, tap the Search button to open the search screen.

On the search screen, tap the search field and type {location} verbatim—never reformat or round it.

Press enter to run the search.

In the search results list, tap the first result to open the place panel.

On the place panel, tap the Favorites star, not the marker control next to it—they write to different stores.

In the dialog that appears, accept the name the app proposes; do not edit it.

Confirm the dialog to save the favorite, then return to the map.

Trap: The search field accepts both place names and coordinate pairs, so enter {location} exactly as given. Trap: Only the star writes to favorites.gpx, which the oracle reads; the marker control does not.
