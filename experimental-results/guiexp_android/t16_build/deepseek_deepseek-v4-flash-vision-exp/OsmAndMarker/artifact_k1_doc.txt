On the launcher screen, tap the OsmAnd app icon.
On the map screen, tap the Search button to open the search screen.
Tap the search input field and clear any pre-filled text.
Type {location} exactly as given — the field takes either a place name or a lat, lon pair, so never reformat, round, or split it.
Wait for the search results, then tap the first result row.
On the place panel, tap the MARKER control — not the favorites star next to it.
Only MARKER writes to the map_markers table the oracle reads; the star writes to a different store.
The marker is saved on the tap; no confirmation dialog follows.
