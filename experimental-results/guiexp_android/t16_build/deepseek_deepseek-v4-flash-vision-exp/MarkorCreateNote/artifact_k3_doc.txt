Open Markor.
On the main screen, tap the "Create a new file or folder" button.
The create-note dialog appears. It has a Name field and a small extension field.
In the Name field, clear any pre-filled placeholder text, then type the part of {file_name} before the last dot.
In the extension field, type the part of {file_name} from the last dot onward, including the dot.
Tap OK to confirm and open the note editor.
In the note editor, tap the note content area to focus it.
Type {text} into the content area.
Navigate back to save the note.
