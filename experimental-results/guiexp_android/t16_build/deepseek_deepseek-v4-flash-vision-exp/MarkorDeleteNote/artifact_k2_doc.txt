Open Markor. The file list screen appears.
On the file list, find the row whose title is exactly {file_name}. The list contains other notes, so match by title, not by position.
If the row is not visible, scroll the list until it appears.
Long-press the target row. This opens a context menu.
In the context menu, tap "Delete".
A confirmation dialog appears. Tap "OK" to confirm the deletion.
