Open the Markor app. The main screen shows the file list.

In the file list, locate the row whose title is exactly {file_name}. Other notes are present, so match by title only, never by row position.

If the target row is not visible, scroll the list until it appears.

Long-press the target row. This enters selection mode and shows a top bar with a Delete icon.

Tap the Delete icon in the selection top bar. This opens a confirmation dialog.

In the confirmation dialog, tap OK to confirm the deletion.

The note is deleted. Leave every other note untouched.
