Open Simple Calendar Pro.
Navigate to the month containing {year}-{month}-{day}.
Tap the {day} cell in that month view.
Tap New Event.
If an event-type chooser appears, tap the row titled Event.
On the event screen, replace the Title field text with {event_title}.
Replace the Description field text with {event_description}.
If a default reminder row is present, delete it.
Tap the start date row; set it to {year}, {month}, {day}; confirm OK.
Tap the start time row; in the 24-hour picker, set the hour to {hour} and the minutes to the start of the hour; confirm OK.
Calculate the end time by adding {duration_mins} minutes to the start time.
If the calculated end time changes the date, set the end date to that resulting date.
If needed, tap the end date row; set the end date; confirm OK.
Tap the end time row; set the calculated 24-hour end hour and end minute; confirm OK.
Tap Save.
