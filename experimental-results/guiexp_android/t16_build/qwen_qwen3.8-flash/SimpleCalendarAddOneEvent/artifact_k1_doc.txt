Open Simple Calendar Pro.
On the main calendar screen, navigate to {year}-{month}-{day}.
Tap the visible day cell for {day} in {month}/{year}.
Tap New Event.
Tap Event to open the event editor.
Scroll down if needed; Title and Description fields appear before date/time rows.
Tap the Title field and enter {event_title}.
Tap the Description field and enter {event_description}.
There is no duration field; encode {duration_mins} as the end time.
Date and time are separate rows; edit each in its own picker.
If the start date is not {year}-{month}-{day}, tap the start date row.
In the date picker, select {year}, {month}, and {day}, then tap OK.
Tap the start time row.
In the 24-hour time picker, select {hour} as the hour and the minute for the start of that hour.
Tap OK to confirm the start time.
Compute the end time by adding {duration_mins} minutes to the start time.
If the end date is later than the start date, tap the end date row, select the computed end date, and tap OK.
Tap the end time row.
In the time picker, select the end hour and end minute after wrapping to a valid 24-hour time.
Tap OK to confirm the end time.
Tap Save.
Return to the main calendar screen.
