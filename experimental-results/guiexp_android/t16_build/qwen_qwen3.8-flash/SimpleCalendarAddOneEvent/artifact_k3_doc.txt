Open Simple Calendar Pro.
On the main calendar, navigate to the month containing {year}-{month}-{day}.
Tap the calendar cell for {day}.
Tap the New Event control.
Tap the Event option to open the event editor.
Enter {event_title} in the first editable field, labeled Title.
Enter {event_description} in the next editable field, labeled Description.
Check the start date row; if it does not show {year}-{month}-{day}, open it and select that date.
Confirm any date picker with OK.
Open the first time row, which is the start time.
Set the start time to {hour}h on a 24-hour clock, on the hour.
Confirm the start-time picker with OK.
Open the second time row, which is the end time.
Set the end time to {hour}h plus {duration_mins} minutes.
If needed, split that duration across the end-time hour and minute controls.
Confirm the end-time picker with OK.
Do not search for a duration field; duration is stored only by the end time.
If a pre-filled reminder row blocks the form, delete it before saving.
Tap Save.
The event editor closes and returns to the main calendar.
