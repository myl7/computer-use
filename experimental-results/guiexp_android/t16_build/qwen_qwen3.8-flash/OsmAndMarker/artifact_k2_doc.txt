Open OsmAnd and wait for the map screen.
Tap the Search control on the map screen.
If the search field already contains text, clear it.
Type the entire {location} value verbatim into the search field.
Do not split, round, or reformat {location}.
Use the same field for a place name or a coordinate pair.
Wait for search results to load.
If no result appears, tap Increase search radius and wait.
If still no result, clear the field and type {location} again.
If the search field is missing, tap Navigate up and then tap Search again.
Tap the first search result row.
Accept a first result that shows formatted degrees for a coordinate query.
Wait for the place panel or map context menu to open.
Tap Marker in the place panel.
Do not tap the Favorites/star control; it writes to a different store.
Stop after tapping Marker; the marker is stored immediately and no confirmation dialog follows.
