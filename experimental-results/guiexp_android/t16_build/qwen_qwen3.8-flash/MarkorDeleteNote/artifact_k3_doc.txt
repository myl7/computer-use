Open Markor.
Wait for the files list screen.
Do not type {file_name}; use it only to match the row title.
Scroll down the file list until a row titled {file_name} is visible.
If the visible title omits the extension, match the same base name.
Never choose by row position; verify the title matches {file_name}.
Long-press the matching row to enter selection mode.
Tap the Delete icon in the selection top bar.
If Delete is not visible, open overflow and tap Delete.
Wait for the delete confirmation dialog.
Tap OK to confirm deletion.
Verify the target row is gone and all other notes remain.
