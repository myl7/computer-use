Open Markor and wait for the file list screen.
Scroll the file list until a row titled {file_name} is visible.
If needed, scroll further and look for {file_name} without its extension.
Select the row by exact title match only; never rely on row position.
Long-press the matched row to enter selection mode.
Confirm the selection top bar appears for the selected note.
Tap the Delete icon in the selection top bar.
If the Delete icon is hidden, open the overflow menu and choose Delete.
Wait for the delete confirmation dialog to appear.
Tap OK on the delete confirmation dialog.
Wait for the file list to refresh.
Verify that {file_name} is absent from the list.
If the note remains, return to the file list and repeat the selection and delete steps.
Do not delete any other note.
