Open Markor.
If the Files list is not showing, navigate to the Files list screen.
Scroll down until the file list row titled {file_name} is visible.
Match the row by its title {file_name}; never choose a row by position.
If no exact {file_name} title is present, choose the unique row whose base title matches {file_name} without an extension.
Long-press that row to enter selection mode.
Check that the selection top bar identifies the selected note as {file_name}.
Tap the Delete icon in the selection top bar.
If Delete is not shown, tap More options and choose Delete.
Wait for the delete confirmation dialog.
Tap OK in the confirmation dialog.
Verify only {file_name} was removed and other notes remain.
