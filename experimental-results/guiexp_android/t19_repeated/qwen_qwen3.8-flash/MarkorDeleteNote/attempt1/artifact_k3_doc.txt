Open Markor.
On the Markor file list screen, use {file_name} to identify the target note row title.
Match the row by its exact title, not by row position, and leave other notes alone.
If the matching row is not visible, scroll the file list until it appears.
Long-press the matching row to select it and reveal the selection top bar.
On the selection top bar, tap the Delete icon.
If the Delete icon is hidden, open the selection overflow menu and tap Delete.
On the delete confirmation dialog, tap OK to confirm.
Return to the file list and verify {file_name} is no longer present.
