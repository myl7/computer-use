Open Markor and wait for the Files list screen.
If {file_name} is not visible, scroll the Files list down.
Find the row whose title matches {file_name}; ignore row position.
Do not select any other note in the list.
Long-press the matching note row to enter selection mode.
Wait for the selection top bar to appear.
Tap the Delete icon in the selection top bar.
Wait for the delete confirmation dialog.
Tap the confirmation button to delete only the selected note.
