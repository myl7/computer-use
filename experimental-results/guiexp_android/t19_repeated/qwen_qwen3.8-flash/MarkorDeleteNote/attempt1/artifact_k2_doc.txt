Open Markor and wait for the file list screen.
If needed, navigate back or into the folder that contains the notes.
Use {file_name} as the target note title; do not enter it into a text field.
Scroll the file list until the row titled {file_name} is visible.
Prefer an exact visible title match to {file_name}; if the extension is not displayed, use the matching stem.
Long-press the target row to enter selection mode.
Confirm the selection bar shows {file_name} selected and no other note is selected.
If the wrong note is selected, clear the selection and long-press the row titled {file_name} again.
On the selection top bar, tap Delete.
If Delete is not visible, open the overflow menu and tap Delete.
Wait for the delete confirmation dialog.
Tap OK in the dialog to confirm.
If the dialog remains, tap OK again; if deletion did not occur, return to the file list and retry from the target row.
Verify the file list no longer contains {file_name} and all other notes remain.
