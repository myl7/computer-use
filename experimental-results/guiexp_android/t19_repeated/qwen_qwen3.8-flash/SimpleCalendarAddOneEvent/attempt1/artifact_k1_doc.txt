Open Simple Calendar Pro.
On the calendar screen, navigate to {month} {year} if needed.
Tap the day cell for {day}.
Tap New Event, then choose Event to open the Event editor.
On the Event editor, enter {event_title} in the Title field.
Enter {event_description} in the Description field.
Do not look for a duration field; set the end time from the start time and {duration_mins}.
If the start date is not {year}-{month}-{day}, tap the start date row, set that date, and confirm with OK.
Tap the start time row.
In the start time picker, use the 24-hour clock, set the hour to {hour}, set the minute to the start-of-hour option, then confirm with OK.
Calculate the end date and end time by adding {duration_mins} minutes to the start date and time.
Set the end hour to the carried hour and the end minute to the leftover minutes.
If the calculated end date differs from the start date, use that later date for the end date.
Tap the end time row.
In the end time picker, set the hour and minute to the calculated end time, then confirm with OK.
If the end date row is present, tap it, set the calculated end date, and confirm with OK.
Tap Save.
