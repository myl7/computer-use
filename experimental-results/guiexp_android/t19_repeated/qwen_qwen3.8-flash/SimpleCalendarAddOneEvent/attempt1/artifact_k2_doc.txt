Open Simple Calendar Pro.
On the month view, navigate to {year}-{month} and tap the cell for {day}.
Tap New Event, then tap the Event row to enter the event editor.
Enter {event_title} in the Title field.
Enter {event_description} in the Description field.
Delete any default reminder row so it does not affect the event.
Confirm the start date row shows {year}-{month}-{day}; if not, open it, choose the date, and tap OK.
Tap the first time row to open the start-time picker.
Choose {hour} as the start hour in 24-hour time.
Tap OK to confirm the start time.
Treat duration as encoded in the end time, not as a separate field.
Tap the second time row to open the end-time picker.
If the picker shows a list of minute or duration choices, match the option for {duration_mins} minutes.
Otherwise set the end hour and minute so the end time is the start time plus {duration_mins} minutes.
If this crosses midnight, open the end date row, choose the next day, and tap OK.
Tap OK to confirm the end time.
Tap Save.
Verify the saved event on {year}-{month}-{day} has title {event_title} and the intended duration.
