Open Simple Calendar Pro.
If needed, navigate the main calendar screen to {year} and {month}.
Tap the day cell for {day} in the displayed month view.
Tap New Event.
Tap the Event row by its title.
Enter {event_title} into the Title field.
Enter {event_description} into the Description field.
If a reminder row is present and not needed, delete it.
Verify the start date is {year}-{month}-{day}; if not, tap the start date row.
If the date picker opens, select {year}, {month}, and {day}, then confirm OK.
Tap the first time row to open the start-time picker.
Select hour {hour} in the start-time picker.
Ensure the start minute is zero minutes.
Confirm the start-time picker with OK.
Tap the second time row to open the end-time picker.
There is no duration field; set the end time to {hour}h plus {duration_mins} minutes.
If {duration_mins} contains whole hours, increase the end hour by those whole hours.
Tap the minute selector in the end-time picker.
Select the minutes remainder after whole hours.
If the end time crosses midnight, advance the end date accordingly.
Confirm the end-time picker with OK.
Check that the event lasts {duration_mins} minutes.
Tap Save on the event editor.
Return to the main calendar screen.
