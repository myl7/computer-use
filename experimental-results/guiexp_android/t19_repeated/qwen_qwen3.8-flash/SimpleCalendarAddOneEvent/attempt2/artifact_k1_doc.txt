Open Simple Calendar Pro.
Navigate the calendar to month {month} of {year} if it is not already visible.
Tap the day cell labeled {day} in that month, not an adjacent-month day.
Tap New Event; if a type chooser appears, choose Event.
On the event screen, clear and type {event_title} into the Title field.
Clear and type {event_description} into the Description field.
Open the Start date row and set the date to {year}, month {month}, day {day}.
Confirm the date picker with OK.
Open the Start time row and set the hour to {hour} and the minute to the start of the hour.
Confirm the time picker with OK.
There is no duration field; compute the End time by adding {duration_mins} minutes to the Start time.
Open the End time row.
Set the End time to the computed 24-hour value, carrying into the next hour or day if needed.
If an End date row is visible, set it to the date containing the computed End time.
Confirm every picker with OK before leaving it.
Tap Save.
