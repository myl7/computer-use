Open Simple Calendar Pro.
On MainActivity, navigate to {year} and {month} if needed.
Tap the calendar cell for {day}.
Tap New Event.
Tap the Event option to open the event editor.
Type {event_title} in the Title field.
Type {event_description} in the Description field.
If the start date row does not show {year}-{month}-{day}, tap it, set the date, and confirm OK.
Tap the start time row, the first time row after the date row.
In the start-time dialog, use 24-hour time and select hour {hour} and the beginning-of-hour minute value.
Confirm the start-time dialog with OK.
There is no duration field; represent {duration_mins} as the end time.
Compute the end time by adding {duration_mins} minutes to {hour}h.
Tap the end time row, the second time row after the date row.
Do not rely on the displayed end time; it may match the start time.
In the end-time dialog, select the computed end hour and end minute.
If the computed end time crosses midnight, advance the end date to the following day if an end date row is shown.
Confirm the end-time dialog with OK.
If a default reminder row is present and unwanted, delete it.
Save the event.
