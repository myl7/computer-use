Open Simple Calendar Pro and wait for the calendar main screen.
Navigate to the calendar month for {month} in {year}; use month or year controls if needed.
Tap the calendar cell for day {day} to select the event date.
Tap New Event; if a creation menu appears, tap Event.
On the event screen, fill the first text field, Title, with {event_title}.
Fill the next text field, Description, with {event_description}.
If a default reminder row is visible and blocks the date/time rows, remove it.
Check the start date row below the text fields; if it does not show {year}-{month}-{day}, tap it.
In the date picker, set year {year}, month {month}, and day {day}, then tap OK.
Tap the first time row, the start time, to open the start-time picker.
Set the start hour to the control matching {hour} and set the start minute to zero.
Tap OK to confirm the start time.
Add {duration_mins} minutes to the start time to obtain the end hour and end minute.
If the end time passes midnight, advance the end date by the needed number of days.
Tap the second time row, the end time; do not identify it by its displayed text.
In the end-time picker, set the computed end hour and end minute.
If an end date row is present and the end time advances the day, set the computed end date.
Tap OK to confirm the end time.
Verify the title, description, start date/time, and end date/time match the goal.
Tap Save.
Dismiss any remaining confirmation or picker dialog with OK or the visible confirm button.
