OPERATION: Add a location marker for {location} in the OsmAnd maps app.

1. Launch OsmAnd and wait for the map screen; confirm its map controls (e.g. "Configure map", Search) are visible before continuing.
2. Tap the Search button on the map screen to open the search overlay.
3. Tap the search input field (hinted "Type to search all") to focus it.
4. Type {location} VERBATIM into that one field — never reformat, round, translate, or split it; the same field accepts place names and 'lat, lon' pairs.
5. Wait for the results list; if nothing refreshes automatically, press the keyboard's enter/search key once.
6. If the list shows the no-results state with an "INCREASE SEARCH RADIUS" control, tap it once; widen the radius only until result rows appear — never loop on this control, it does not re-run the search.
7. If a place-name query still returns nothing, tap the Clear (X) button in the search field, retype {location} once, then widen the radius again.
8. Select the FIRST result row: a non-editable row whose displayed text contains {location}.
9. Coordinate queries are shown reformatted (e.g. "47.06888° N, 9.50616° E"), so match the row by its numbers, not the raw string.
10. Ignore the search field itself when matching — it also contains the query text.
11. Tapping the result opens the place/context panel over the map.
12. On the panel, tap the control labeled "Marker" to add the marker.
13. Do NOT tap the favorites/star icon next to it: favorites and markers are different stores, and only the marker counts for this task.
14. The marker is saved on that tap; no confirmation dialog follows — the task is complete once the marker action is applied.
15. If "Marker" is not on the panel, the result tap failed to open it: go back and reselect the first result row.
