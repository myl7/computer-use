Open the OsmAnd app and wait for the map screen (controls: Search, Configure map, My Location).
Tap the Search button (magnifier, description "Search") on the map screen to open the search overlay.
Find the search field with the hint "Type to search all".
If that field is pre-filled with old text, tap its "Clear" (X) button first so the new query replaces it.
Tap the field and type {location} exactly as given: never reformat, round, split, or autocomplete it — the same field accepts place names and "lat, lon" pairs.
Wait for live results; if none appear, press the keyboard's search/enter key once.
Trap: if the screen shows "INCREASE SEARCH RADIUS", the search found nothing — do not tap it or widen the radius repeatedly; instead verify the query matches {location} verbatim, clear the field, retype, and search again.
Tap the FIRST search-result row, matched by title: its text should contain the {location} name or its coordinate numbers.
Trap: coordinate results are often displayed reformatted (for example with degree and N/E/W letters); that is still the right row if the numbers match — do not require an exact string match.
Tapping the result opens the map with the place/context panel for that location.
On that panel, tap the action labeled "Marker" (marker/pin control in the actions row).
Trap: do NOT tap the favorites star next to it — the star saves a Favorite, not a marker, and only the Marker action writes the marker this task requires.
The marker is saved immediately when you tap Marker; no confirmation dialog follows, so do not wait for or dismiss one.
The task is complete once the marker tap has registered on the place panel.
