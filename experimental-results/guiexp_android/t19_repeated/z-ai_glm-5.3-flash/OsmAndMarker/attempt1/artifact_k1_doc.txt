Task: Add a location marker for {location} in the OsmAnd maps app.

1. Open OsmAnd and wait for the main map screen (it shows a "Configure map" control).
2. Tap the Search button (magnifying-glass icon) on the map screen to open the search screen.
3. Tap the search input field hinted "Type to search all".
4. Type {location} VERBATIM — never reformat, round, abbreviate, or split a "lat, lon" pair; this single field accepts both place names and coordinates.
5. Submit the search (keyboard search/enter action).
6. If a "no results" state appears with an "INCREASE SEARCH RADIUS" label, tap it; tap it repeatedly if needed until results load — this label only exists while the search has failed.
7. If a stale or wrong query sits in the field, tap the field's Clear (X) button first, then retype {location}; never append to an existing query.
8. From the results list, tap the first result row (its title should correspond to {location}).
9. A place panel slides up over the map; tap the MARKER control on this panel.
10. TRAP: do NOT tap the favorites star next to the MARKER control — they write to different stores, and only the marker store is checked.
11. The marker is saved on the tap itself; no confirmation dialog follows — the task is complete once tapped.
12. If you need to leave the results list without searching again, use the "Navigate up" back arrow rather than clearing or restarting the app.
