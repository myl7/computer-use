Open Simple Calendar Pro and wait for the month view with the floating New Event (+) button.
Tap the New Event button; if a menu of entry types appears, choose "Event" to open the new-event editor.
Tap the Title field at the top of the editor and enter {event_title}.
Tap the Description field directly below Title and enter {event_description}.
The rows under the text fields come pre-filled with the device's frozen current date and time; each one must be replaced with the target values, not just confirmed.
Tap the Start date row. In the date picker dialog, if {month} {year} is not already shown, step to it with the dialog's month/year arrows.
Tap day {day} in the month grid, then tap OK — every picker dialog must be confirmed with OK or the change is discarded.
Tap the Start time row. In the time picker, select hour {hour} on the 24-hour dial (00–11 on the inner ring, 12–23 on the outer ring).
Then select minutes 00 so the event starts exactly at {hour}:00, and tap OK.
Tap the End time row; it may have auto-shifted when you changed the start time, so always open it and set it explicitly.
There is no duration field: the event length is set entirely through the end time.
In the end-time picker, set the clock to the start time plus {duration_mins} minutes — if {duration_mins} is under 60 use it as the minute, otherwise advance the hour by the extra hours and use the leftover minutes.
Tap OK to confirm the end time.
If the keyboard is still open, dismiss it (Done or back) so the top bar is reachable.
Tap the Save checkmark in the top bar; the app returning to the month view confirms the event was created.
