Markor note deletion — operation document

1. Open the Markor app and wait until its main file-list screen is shown.
2. On the file list, find the row whose exact title equals {file_name}; several other notes are listed and must be left untouched.
3. Match the row by its title text only, never by its position in the list.
4. If the row titled {file_name} is not visible, scroll the list down and search again.
5. Long-press the row titled {file_name} to put it into selection mode; the top bar changes to a selection bar.
6. Before continuing, check the selection bar indicates the target note {file_name} is the selected one; if a wrong note is selected, cancel and redo the long-press on the correct row.
7. Tap the Delete icon shown in the selection top bar; it deletes only the currently selected note.
8. A confirmation dialog titled "Confirm Delete" appears; its message mentions {file_name} (full name or name without extension).
9. If the dialog does not reference {file_name}, cancel it and restart from the long-press step.
10. Tap the OK button in the dialog to confirm the deletion.
11. Wait for the list to refresh and verify the row {file_name} is gone while every other note is still present.
