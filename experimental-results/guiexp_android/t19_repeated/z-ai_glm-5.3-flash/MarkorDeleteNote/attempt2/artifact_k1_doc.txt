Markor — delete the note named {file_name}

1. Open the Markor app and wait for the file list (main screen) to load.
2. If Markor did not open, return to the home screen and launch Markor again.
3. On the file list, find the row whose title is exactly {file_name}; match by title, never by row position.
4. If that row is not visible, scroll the list down and search again.
5. Long-press the {file_name} row; this selects it and replaces the top bar with a selection bar.
6. Verify the selection bar is showing and the target note is the selected item.
7. Tap the Delete icon in the selection top bar; it deletes only the currently selected note.
8. A "Confirm Delete" dialog appears; its message names the note, with or without the file extension.
9. If no such dialog appears, do not confirm — the wrong note may be selected.
10. Tap OK in the dialog to delete the note permanently.
11. Verify {file_name} is gone from the list and every other note is untouched.
