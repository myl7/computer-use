Delete the note in Markor named {file_name}.

1. Open the Markor app and wait for its main note-list screen (app title "Markor" with a "Create a new file or folder" action visible).
2. If Markor did not reach the main screen, go to the home screen, open Markor again, and wait.
3. Scan the note list for the row whose title is exactly {file_name}; never pick a row by position — several other notes are listed.
4. If no row titled {file_name} is visible, scroll the list down and search again.
5. Long-press the row titled {file_name} to select it; selection mode must activate.
6. Confirm the selection top bar appears with a Delete action; if it does not, the long-press missed — retry on the correct row.
7. Tap the Delete icon in the selection top bar.
8. A "Confirm Delete" dialog opens; its message names the target note, possibly with or without the file extension.
9. If the dialog is absent or names a different note, cancel it, reselect the row titled {file_name}, and tap Delete again.
10. Tap OK in the "Confirm Delete" dialog to confirm.
11. Wait for the dialog to close and the note list to refresh.
12. Verify {file_name} no longer appears in the list and every other note is untouched.
