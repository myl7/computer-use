OPERATION: Delete the note named {file_name} in Markor.

1. Launch the Markor app and wait for the file list (main screen) to load.
2. Confirm you are on the main screen: it shows the app title "Markor" and a create-new-file button.
3. Locate the list row whose content description contains "File {file_name}"; match by the exact title {file_name}, never by row position.
4. If the row is not visible, scroll the list down and search again.
5. Long-press the matching row to select it; do not tap (a tap would open the note).
6. Verify the row for {file_name} is now in selection mode.
7. In the selection top bar, tap the "Delete" (trash) icon; it only deletes the currently selected note, so confirm the selection is the target first.
8. A "Confirm Delete" dialog appears, naming the note ({file_name} or its name without extension). Verify it is the right note.
9. Tap "OK" in the dialog to confirm the deletion.
10. Confirm the note {file_name} no longer appears in the file list; all other notes must remain untouched.

TRAPS:
- The target row must be found by its title {file_name}; other notes look identical and positions shift.
- Deletion is a two-stage action: selection via long-press, then the top-bar delete icon, then dialog confirmation.
- If the launch is slow, re-check the screen before giving up.
