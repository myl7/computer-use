OPERATION: Delete the note in Markor named {file_name}

1. Open the Markor app; wait for the main file list screen (title "Markor" / "Create a new file or folder" button visible).
2. Locate the note list row whose title matches {file_name} exactly — match by name, never by row position.
3. If the row is not visible, scroll the list down and search again.
4. Long-press the matching row to select it (do not tap, and do not touch any other row).
5. Verify the target row shows as selected before continuing.
6. Tap the "Delete" icon in the selection top bar.
7. A "Confirm Delete" dialog appears, naming the file; verify it references {file_name}.
8. Tap "OK" in the dialog to confirm deletion.
9. Confirm the note {file_name} is gone from the list and all other notes remain.

TRAPS:
- Delete works only on a selected row: it must be long-pressed first, or the Delete button deletes nothing/wrong item.
- The list holds other notes; select strictly by title {file_name}, never by position.
- The row may be off-screen and require scrolling.
- Deletion is not final until the "Confirm Delete" dialog is confirmed with OK.
