OPERATION DOCUMENT: Add an OsmAnd location marker for {location}

1. Start on the Android home screen; if OsmAnd is not already foreground, open the OsmAnd app.
2. Do not rely on home-screen scrolling; if a notification shade or overlay is open, dismiss it first.
3. Wait for the OsmAnd map screen to settle.
4. On the map screen, tap the Search control (magnifier / "Search").
5. Wait for the search screen and locate the editable search field.
6. If the search field contains old text, clear it completely.
7. Type {location} into the search field exactly as given; the field accepts both place names and coordinate pairs.
8. Do not reformat, round, or split the value across fields.
9. Let results load; do not edit the query after typing.
10. In the result list, tap the first search result row for {location}.
11. Wait for the place panel / location details screen.
12. On that panel, tap the MARKER control to add the location marker.
13. Do not tap the favorite star next to MARKER; it writes to a different store.
14. No confirmation dialog follows; the marker is stored on the tap.
15. Optionally verify the marker appears on the map screen.
16. If the place panel does not open, re-tap the first result row, not another row.
17. No further save or confirm step is required.
