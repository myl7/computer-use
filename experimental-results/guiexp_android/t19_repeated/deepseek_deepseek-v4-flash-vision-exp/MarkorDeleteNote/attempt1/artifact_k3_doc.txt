Open Markor.

On the Markor file list screen, locate the row whose title is exactly {file_name}. Do not rely on row position; ignore all other notes.

If the target row is not visible, scroll the list until the row titled {file_name} appears.

Long-press that row to select it.

A top selection bar appears. Tap the Delete icon (trash icon) in that bar.

A confirmation dialog appears. Tap OK to confirm deletion.

The note is deleted. Leave every other note untouched.
