Open Simple Calendar Pro.
On the main screen, tap the button that creates a new event (the floating action button or the "New event" option). If a menu or dialog appears, select the "New event" or "Event" option by its title.
On the new event screen, tap the Title field and type {event_title}.
Tap the Description field and type {event_description}.
Tap the start date row to open the date picker dialog.
In the date picker, navigate to {year}-{month} if needed, select day {day}, and confirm with OK.
Tap the start time row to open the time picker dialog.
In the time picker, set the hour to {hour} and the minutes to 0, then confirm with OK.
Tap the end time row to open the time picker dialog.
In the time picker, set the end time to the start time plus {duration_mins} minutes, then confirm with OK.
Tap the save button to create the event.
Return to the main screen.

Traps: The time picker has separate hour and minute fields; set both. Date and time pickers must each be confirmed with OK. There is no duration field; set the end time explicitly to the start time plus {duration_mins} minutes. The time picker fields may be pre-filled; set them to the desired values.
