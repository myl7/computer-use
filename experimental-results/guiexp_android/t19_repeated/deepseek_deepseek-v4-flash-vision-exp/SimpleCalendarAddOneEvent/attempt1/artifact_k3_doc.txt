1. Open the Simple Calendar Pro app.
2. On the main calendar screen, tap the "New Event" button to open the event editor.
3. Tap the Title field and type {event_title}.
4. Tap the Description field and type {event_description}.
5. Tap the start date row (it shows a pre-filled date) to open the date picker.
6. If the picker is not showing the target month and year, use the month navigation arrows to reach them (the picker starts on October 2023).
7. Tap the day cell showing {day}, then tap OK to confirm the date.
8. Tap the start time row (it shows a pre-filled time) to open the time picker.
9. In the time picker, the hour and minute are separate fields; tap the hour cell for {hour} (described as "{hour} hours").
10. Tap the minute cell for 00, then tap OK to confirm the start time.
11. Tap the end time row to open the end time picker.
12. Select the hour and minute that are {duration_mins} minutes after the start time (if the result crosses midnight, also update the end date row to the next day).
13. Tap OK to confirm the end time.
14. Tap the Save button to create the event.
