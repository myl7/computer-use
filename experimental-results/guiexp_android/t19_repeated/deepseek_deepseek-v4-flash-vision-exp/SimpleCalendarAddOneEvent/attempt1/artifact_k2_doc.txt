1. Open Simple Calendar Pro.
2. On the calendar screen, tap the floating "+" new event button to open the event creation screen.
3. On the event creation screen, tap the Title field and type {event_title}.
4. Tap the Description field and type {event_description}.
5. Tap the start date row to open the date picker dialog.
6. In the date picker, navigate to {year}-{month}-{day}. If the shown month/year is not the target, tap the year/month header and select the matching row; then tap the day whose title matches {day}. Confirm with OK.
7. Tap the start time row to open the time picker dialog.
8. In the 24-hour time picker, clear the pre-filled hour and minute, then set the hour to {hour} and the minute to 00; confirm with OK.
9. Tap the end time row to open the time picker dialog.
10. Compute the end time as {hour}:00 plus {duration_mins} minutes, carrying over to the next hour or day if needed.
11. In the end time picker, clear the pre-filled hour and minute, then set the hour and minute fields separately to the computed values; confirm with OK.
12. Tap the save button (checkmark) to create the event and return to the calendar.
