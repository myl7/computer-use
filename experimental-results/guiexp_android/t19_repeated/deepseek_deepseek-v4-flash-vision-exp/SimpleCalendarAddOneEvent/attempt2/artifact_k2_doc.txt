Open Simple Calendar Pro from the launcher.
On the main calendar screen, navigate to the month {year}-{month} if needed.
Tap the day {day} on the calendar to select the event date.
Tap the new event button (the plus icon) to open the event editor.
In the event editor, the Title and Description fields are at the top; the start date row and start/end time rows are below them.
Tap the Title field and type {event_title}.
Tap the Description field and type {event_description}.
Tap the start date row. In the date picker, ensure the month is {month}, select {day}, and confirm with OK.
Tap the start time row. In the time picker, set the hour to {hour} and the minute to 0, then confirm with OK.
Tap the end time row. In the time picker, set the end time to {duration_mins} minutes after the start time, then confirm with OK.
Tap the Save button (checkmark) to create the event and return to the main screen.

Notes:
- There is no duration field; the end time must be set manually.
- The device clock is 24-hour; use {hour} as given.
- Date and time pickers each require an OK tap to confirm.
- The end time is the start time plus {duration_mins} minutes; if the sum crosses an hour, set the end hour and end minute accordingly.
