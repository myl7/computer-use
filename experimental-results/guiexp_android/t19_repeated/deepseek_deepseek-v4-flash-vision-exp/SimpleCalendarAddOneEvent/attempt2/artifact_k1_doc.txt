Open Simple Calendar Pro.
Tap the new-event button (plus icon) to open the new-event screen.
Tap the Title field and enter {event_title}.
Tap the Description field and enter {event_description}.
Tap the start date row (labeled Start date) to open the date picker.
In the date picker, navigate to {month}/{year} if needed, select {day}, then tap OK.
Tap the start time row (labeled Start time) to open the time picker.
In the 24-hour time picker, set the hour to {hour} and the minute to 0, then tap OK.
Tap the row labeled End time (not Start time) to open the time picker.
There is no duration field; set the end time manually to the start time plus {duration_mins} minutes, carrying into the next hour(s) if needed, then tap OK.
Tap Save to create the event.
