Open Simple Calendar Pro.
On the main calendar screen, tap the New Event button.
On the event creation screen, tap the Title field and type {event_title}.
Tap the Description field and type {event_description}.
Tap the start date row to open the date picker.
In the date picker, ensure it shows {month} {year}; navigate if needed, then tap the day cell for {day} and tap OK.
Tap the start time row to open the time picker.
In the time picker, select the hour {hour} and minute 00, then tap OK.
Tap the end time row to open the time picker.
In the end time picker, select the hour and minute that are {duration_mins} minutes after {hour}:00, then tap OK.
Tap the Save button to create the event.

Traps: There is no duration field; the end time is the only way to set the event length. Each picker dialog must be confirmed with OK. The time picker has separate hour and minute columns; select both. The device clock is 24-hour, so times are shown as HH:MM.
