\section{Live GUI execution}
\label{app:live}
\label{sec:live}

We test agent fallback and call-cost reservations on the OpenApps Calendar web application \citep{ullrich2025openapps}.
This study uses a fixed program and a scheduled compilation attempt, so it does not evaluate PACE's online compilation choice.

\subsection{Paired task execution}
Four seeds specify event title, date, description, location, URL, and invitees.
Each runs in a clean interface, with a renamed submit button, and with a blocking dialog, giving twelve agent/program pairs with matching initial states.
Both paths use GLM 5.3 Flash and the same natural-language goal.
The agent reads screenshots and an accessibility tree in headless Chromium.
The program receives a model-extracted binding and uses Playwright locators.
An execution error triggers agent fallback from the current GUI state, without resetting it.
A task has a total limit of twenty model calls.
The evaluator checks the created event and preservation of unrelated application state.

\subsection{Reservations}
Before a call, the runner reserves a charge using declared input/output limits and the recorded price schedule.
A confirmed bill replaces the reservation.
An unsuccessful response or a response without a confirmed bill ends the task without a retry and retains the reserved charge.
All $221$ physical requests pass the recorded admission arithmetic.
Of these, $215$ have verified bills and six remain unsettled.
Known charges total USD $0.121359$, with an upper bound of USD $0.363432$ after including unsettled reservations.

The main reference adds USD $0.08$ per scheduled task and permits $1.25$ times the cumulative reference.
A separate attempt, after three completed agent traces, costs USD $0.006872$, passes its predeclared two-instance gate, and leaves the fixed serving program unchanged.
Its charge is included in the cumulative cost checked against the main budget, but is excluded from the serving-cost comparison.
This one-call attempt has no repair and differs from the five-binding gate in the main measurement.

Four additional tasks use a separate reference of USD $0.02$ per arrival.
Two succeed, one stops on a billing interruption, and the first is denied because its USD $0.039834$ binding reservation exceeds the initial USD $0.025$ allowance.
No model call or GUI service occurs for that denied task, although it still increases the cumulative reference by USD $0.02$.
All recorded prefixes remain within their declared ceilings.
These references are supplied allowances, not measured bills from running every task with the agent, and the denial falls outside the theorem's affordable-default-service premise.

\subsection{Cost bounds with unsettled bills}
For each request without a confirmed bill, we retain the known charge as a lower bound and the reservation as an upper bound.
Across all twelve pairs, mean serving bills are bounded by $[8.142,21.590]$ milli-USD for the agent and $[1.202,4.564]$ for the program path.
We do not restrict this comparison to the eight pairs with fully settled bills.
For a paired difference, the lower endpoint subtracts the agent's upper bill from the program's lower bill.
The upper endpoint uses the opposite endpoints.
The mean difference is bounded by $[-20.388,-3.577]$ milli-USD.

We enumerate all $4^4=256$ ordered bootstrap draws of the four seed clusters, retaining both policies and all three conditions within each selected seed.
Using linear interpolation, we combine the $2.5$ percentile of the lower mean differences and the $97.5$ percentile of the upper mean differences.
This gives a $95\%$ envelope of $[-33.017,4.621]$ milli-USD, which includes zero.
It propagates billing bounds through the bootstrap, rather than providing an exact-bill confidence interval.
The four clusters, one task family, and provider interruptions limit population inference and conclusions about successful GUI service.
