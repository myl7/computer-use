\section{Conclusion}
\label{sec:conclusion}

Compiling a computer-use task can make later runs cheap but requires substantial initial spending whose amount is uncertain.
PACE measures both costs and decides when to compile under a budget relative to the cost of running every task with the agent.
With valid action-cost bounds, the budget limits cost after every arrival, including failed compilations and streams that end before payback.
In the experiments using recorded arrival orders, PACE reduces token costs by $21.9\%$ relative to ReAct on average, while ablations separate the effects of compilation selection, failed compilation costs, and cost protection.
